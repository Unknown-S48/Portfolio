# Personal Portfolio Website
- a Modern, dark/light-mode portfolio showcasing my software engineering skills, eperience, and projects.
# Technologies Used
Frontend            HTML5, CSS3, JavaScript
Styling             Custom CSS with CSS Variables
Icons               Font Awesome 6
Version Control     Git, GitHub
Deployment          GitHub Pages
# Features
## Dark/Light mode
- Toggle between dark and light themes
- User preference saved in browser storage
- Smooth color transitions
## Modern UI Design
- Clean, professional layout
- Complementary color palette 
- Smooth animations and hover effects
## Fully Responsive
- Optimized for desktop, tablet and mobile devices
- Flexbox and CSS Grid layout
## Resume Download
- One-click CV download button
- Professional PDF resume attached
## Secial Integration
- GitHub and LinkedIn links
- Direct email contact
## Experience Section
- Chronological order
- Integrated Learning experience highlighted
## Project Showcase
- RealHome property sales website link
- Voting Web Application 
## Hire Me CTA
- Opens Gmail with pre-filled subject and body
- Quick and easy contact for recruiters
# The Process
## What I Learned
- CSS Variables: Implemented theming for dark/light mode using CSS custom properties.
- Pesponsive Design: Cretaed a layout that works seamlessly across all screen sizes.
- Animations: Used CSS keyframes for fade-in, slide, float, and pulse effects.
- Local Storage: Saved user theme preference for persistent dark/light mode.
- Accessibility: Added semantic HTML and ARIA labels for better accessibility.
- Performance: Optimized assets and minimized external dependencies.
## Development Journey
I built this portfolio to showcase my skills and experience to potential employers. The process started with planning the layout and color scheme, then I built the HTML structure, styled it with CSS, and added interactivity with vanilla JavaScript. I paid special attention to animations and visual polish to make a strong first impression.
